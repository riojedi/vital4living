How this works

Mondopoint sizing is based on foot length in centimeters — a Mondo 27 is built for a ~27 cm foot, and sizes step in 5 mm (half-centimeter) increments (REI, SnowSift). This calculator adds 1.0–2.0 cm to your measured foot length for shell room, depending on the fit preference you choose (Performance 1.0 cm / Balanced 1.5 cm / Comfort 2.0 cm); confirm the result with a shell check — a 10–15 mm heel gap (toes touching the shell front) is a performance fit, 15–20 mm recreational (SnowSift). US-to-mondo is an approximate conversion based on sizing charts (men's ≈ US + 18, women's ≈ US + 16.5); measuring foot length in centimeters is more accurate than converting a shoe size (evo, REI). Last width is the forefoot width the boot is built around, and volume class combines last width and instep: low-volume lasts run ~98 mm or less, medium ~99–100 mm, high ~101–102 mm (TheSkiMonster). Flex index is brand-relative, so treat it as a band, not an absolute — flex ratings are a subjective manufacturer number and aren't standardized across brands, so a 100 in one brand can feel different from a 100 in another (TheProSkiAndRide). Brand recommendations reflect general fit tendencies across model lines — a Tecnica Mach1 and a Salomon S/Pro in the same mondo size are not the same fit — so always confirm with the actual boot on your foot (SnowSift).
